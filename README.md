# 傳燈三部曲

**線上遊玩：https://lesliezheung.github.io/Chuandeng/**

三部、一百一十一幕的選擇式互動故事。每一幕都是真實發生過的轉折；選項沒有對錯，只有你這一世的方向。三部曲共用同一份紀錄，前一部的選擇，會在後一部的某一幕以「宿緣」回來找你。

| | 網址 | 內容 |
|---|---|---|
| 一部曲・如是我聞 | [/1/](https://lesliezheung.github.io/Chuandeng/1/) | 佛陀的一生，三十七幕。佛陀的話全部出自漢譯阿含與律藏，並對照巴利經典。 |
| 二部曲・法流三道 | [/2/](https://lesliezheung.github.io/Chuandeng/2/) | 佛滅百年的分裂到十三世紀初超戒寺被毀：佛法在印度的興衰，以及祖師們把它帶往獅子洲、南海、西域、漢地與雪域，三十七幕。 |
| 三部曲・漢傳八宗一千五百年 | [/3/](https://lesliezheung.github.io/Chuandeng/3/) | 東晉到二十一世紀台灣，看漢傳八宗興起、斷絕、渡海、回家，三十七幕。 |

每一部走完，都會看到你的思想傾向、法脈去向，以及你最像哪幾位佛弟子或祖師大德。首頁會記下你的三世。

史料依 CBETA 原典（[cbeta-org/xml-p5](https://github.com/cbeta-org/xml-p5)），以及印順導師、聖嚴法師、星雲大師的著作與平川彰《印度佛教史》核對，各幕附出處；各家說法不同之處兩說並列。

單一網頁，無需安裝；遊玩紀錄只存在你自己的瀏覽器裡。手機可用瀏覽器的「加入主畫面」，之後就像 App 一樣全螢幕開啟，沒網路時也能接著玩。
