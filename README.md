# 傳燈：漢傳八宗一千五百年

**線上遊玩：https://lesliezheung.github.io/chuandeng/**

一個選擇式的互動故事。從東晉亂世山中的一盞油燈，到 1937 年南京城破時不閉的山門、二十一世紀台灣的禪堂，三十三幕都是真實發生過的轉折。你一次次出家，看八宗如何興起、斷絕、渡海、回家；前世的選擇，會在後來的某一世回來找你。

走完之後，你會得到：

- 你的思想最接近哪一宗（三論、法相、天台、華嚴、律、淨土、臨濟、曹洞、密）
- 你這一支法脈今天在哪裡（盛極而斷、東渡回歸、山林不絕、百川歸海）
- 兩者交會的解讀，依四聖諦（苦、集、滅、道）與八正道細說
- 你在人群裡最自然的兩到三個角色
- 綜合三十三幕，你最像哪一位祖師
- 另有三個隱藏結局
